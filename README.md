# MaiScreenWindow

解决maimai屏幕被外壳挡住时，鼠标点不到目标的问题\
运行此程序按住 **Alt**，在屏幕空白处浮出一个小窗\
跟随鼠标并把鼠标周围显示出来,松开就消失\
也可以使用快捷键Ctrl+Alt+O进行固定（松开Alt小窗不消失）

## 运行

releases下载exe文件后运行

## 配置

首次运行会在根目录生成 `config.ini`

托盘右键 ->  打开配置

```
; 更改之后托盘右键 -> 重新加载配置（或重启程序）

; 小窗左上角坐标
x=2168
y=1128

; 小窗大小
width=360
height=280

; 放大倍数
zoom=1

; 开机自启：1 打开 / 0 关闭（默认关闭）
autostart=0
```

更改之后托盘右键 ->「重新加载 config.ini」立刻生效，不用重启

坐标：按住 Alt 时小窗左下角显示当前鼠标坐标
